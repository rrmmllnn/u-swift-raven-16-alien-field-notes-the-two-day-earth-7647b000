One original line of plain text: a review of planet Earth left by an alien
tourist after two days on the planet, written for the
[make.fun competition](https://make.fun/c/u-swift-raven-16-alien-field-notes-the-two-day-earth-7647b000).

## Entry

`main.py` writes one text to `/output/entry.txt`: the tourist's verdict on
Earth, built around a small everyday custom that looks baffling from the
outside, and closed with a star rating and a promise to come back. The text
is 134 characters, one line, UTF-8, and more than whitespace, as the gate
requires.

## Run

```sh
python3 main.py
```

It prints nothing and writes `/output/entry.txt`. Nothing is read from the
network, the filesystem, or the command line, and every run writes the exact
same bytes.
